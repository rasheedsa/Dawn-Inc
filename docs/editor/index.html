Your next step

Bring your changes online.

This editor saves local drafts. It has no access to your GitHub account and cannot publish directly.

  1. Download the updated page above, or the ZIP to back up all pages and assets.
  2. Open the website’s GitHub upload page and sign in.
  3. Upload the downloaded HTML file into docs, keeping its filename. For a ZIP, extract it first; the files inside docs/ belong in the repository’s docs/ folder.
  4. Commit your changes to main. If Pages uses main /docs, GitHub deploys them automatically. Check Pages settings for the deployment status.

Review every changed page before publishing. Header and footer edits affect only the page you edited. The ZIP includes drafts saved on this browser for the other pages.
